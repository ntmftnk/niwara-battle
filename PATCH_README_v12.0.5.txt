追加機能
--------
環境研究の「使用可能条件」で、その研究環境に解禁する要素を指定できます。

1. 使用可能ポケモン
- 25種から任意に許可/除外
- 名前 / 図鑑番号 / タイプ / ID / フォルム名で検索

2. 使用可能技
- 350技から任意に許可/除外
- 技名 / ID / タイプ / 物理・特殊・変化 / 説明で検索
- ポケモンが本来覚えない技は従来どおり採用されません

3. 使用可能特性
- 現行種族が持つ全特性から任意に許可/除外
- ポケモン自身が持つ特性との積集合から構築生成

4. 使用可能持ち物
- ITEM_DEX の全持ち物から任意に許可/除外
- 「持ち物なし」も指定対象
- 持ち物重複禁止は従来どおり。同じ実物アイテムは1チーム1個まで
- 「持ち物なし」は重複可能

一括指定
--------
各カテゴリごとに以下を利用できます。
- 全て
- なし
- 表示中を許可
- 表示中を除外
- 反転

さらに全カテゴリ横断で、検索語に一致する要素を一括許可/除外できます。
例：
- 「でんき」で検索して一致項目を一括許可
- 「berry」で検索して該当持ち物を一括指定

ポケモンとの関連指定
--------------------
- 「選択ポケモンの技・特性を追加」
  選択中のポケモンが覚える技・持つ特性を現在条件へ一括追加します。
- 「選択ポケモンの技・特性だけに絞る」
  技・特性の許可集合を、選択中ポケモンに関連するものだけへ一括変更します。

条件チェック
------------
研究開始前に以下を確認します。
- 技・特性条件まで含めて実際に構築可能なポケモンが6種以上あるか
- 使用可能技が0になっていないか
- 使用可能特性が0になっていないか
- 使用可能持ち物が0になっていないか
- 「持ち物なし」を禁止している場合、重複禁止を満たすため実物持ち物が6種類以上あるか

選択済みポケモンでも、使用可能技が1つもない / 使用可能特性が1つもない場合は実際の構築候補から外れます。
UI上でその数を警告表示します。

研究コアへの反映
----------------
条件は表示だけではなく、sim-core.js の構築生成に直接反映されます。
- ポケモン生成: 許可ポケモンのみ
- 技構成: そのポケモンの習得技 ∩ 許可技
- 特性: そのポケモンの特性 ∩ 許可特性
- 持ち物: 許可持ち物のみ

CPUの公開情報モデルで「相手が持っているかもしれない技」を評価する場合も、禁止技は候補から除外します。

保存・再開
----------
- 初期条件は研究runの config.rules に保存
- IndexedDBの既存DB名/バージョンは変更なし
- 途中保存・再開で同じ条件を維持
- JSON出力には許可ID一覧を完全保存
- 旧バージョンの研究runに rules がない場合は「全要素使用可」として読み込み

履歴・図鑑
----------
- 履歴には条件指定runを「[条件指定]」と表示
- 研究進捗表示には P / 技 / 特性 / 持ち物の許可数を表示
- 図鑑の環境統計にも、そのrunが全解禁か条件指定かを表示

ニワラバトル v11.0.0
======================

【大型アップデート：環境研究シミュレーター】

v10.1.4までの通常対戦・CPU戦・CPU vs CPU・図鑑・ダメージ計算・素早さ比較・PWA機能を維持したまま、
大量のCPU自己対戦を裏で回して環境統計を集計する「環境研究」を追加しました。

■ 環境研究の開き方
ヘッダーの「環境研究」を押します。
研究画面を閉じても、アプリを開いている間はWeb Worker側の計算が続きます。

■ 設定できる項目
- 研究名
- 目標試合数：任意（プリセット 1,000 / 10,000 / 50,000 / 100,000）
- CPU A / CPU B：普通 / 強い / 非常に強い
- 構築方式：難易度連動・強化構築 / 準ランダム / 完全ランダム寄り
- 並列Worker：1 / 2 / 3 / 4 / 6 / 8
- 乱数シード
- 最大ターン数

■ 集計項目
- ポケモン構築採用率
- 3匹選出率
- 先発率
- 選出時勝率
- KO / 被KO
- 技使用回数・有効率・平均ダメージ・KO数
- 持ち物採用率
- 特性採用率
- 性格・能力P分布
- 選出対面参考統計
- 平均ターン数
- 平均交代回数
- A/B勝率・引き分け率

■ 途中保存 / 再開
進捗と集計結果はIndexedDBに保存します。
一時停止して後から再開できます。
ブラウザやPWAを閉じると計算自体は止まりますが、保存済み結果は残ります。

■ 調整前後比較
保存した2つの研究を選択して、
- 構築採用率
- 選出時勝率
の差をポケモンごとに比較できます。
例：技弱体化前50,000戦 vs 弱体化後50,000戦。

■ エクスポート
- JSON：設定・全集計を保存
- CSV：ポケモン / 技 / 持ち物 / 特性の主要統計を保存

■ 再現性
各試合の乱数は「研究シード + 試合番号」から生成します。
同じバージョン・同じ設定・同じシードなら、Worker数や処理順に依存しにくい再現可能な研究を目指しています。

■ AIの情報制限
研究用AIも相手の非公開セットを直接参照しません。
選出では相手の見せ合い6種族だけを使用し、対戦中は現在場にいる種族・HP%・状態・能力ランク・公開済み技などを公開情報スナップショット経由で評価します。
相手の実際の性格・能力P・未公開技・未公開持ち物・未公開特性を技選択・交代判断には渡しません。

■ 高速研究コアについて
大量試行のため、通常対戦UIとは別のヘッドレス戦闘コア sim-core.js をWeb Workerから実行します。
同じ game-data.js を読み、能力値・タイプ相性・主要なダメージ補正・天候・フィールド・壁・設置技・状態異常・反動・回復・交代などを扱います。
一方、極端に特殊な専用技・専用特性の一部は高速化のため簡略化される場合があります。
したがって表示名は「CPU環境統計」とし、人間環境の使用率や1戦単位の完全再現とは区別してください。
個別対戦の正確な確認には通常対戦画面を使用してください。

■ PWA
Service Workerキャッシュ対象に
- sim-manager.js
- sim-core.js
- sim-worker.js
を追加しています。
GitHub Pagesへv11一式を上書き後、「更新確認」からv11へ切り替えられます。

■ 保存パーティー
既存の localStorage キーは変更していません。
同じGitHub Pages URLなら従来の保存パーティーを引き継ぎます。

■ 全データ初期化
v11の「全データ初期化」は、現在編成・保存パーティーに加えて環境研究のIndexedDB履歴も削除します。
確認ダイアログで明示し、同意した場合だけ削除します。

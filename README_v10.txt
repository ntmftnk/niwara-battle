ニワラバトル v10.0.0
======================

v9.1.6 を基準に、指摘された安全性・対戦順序・アクセシビリティ・保守性の問題をまとめて修正した大規模整理版です。

■ 主な修正

1. 「全データ初期化」を安全化
- ボタン名を「初期化」→「全データ初期化」に変更。
- 実行前に、現在編成と最大30件の保存パーティーを削除し元に戻せないことを確認ダイアログで明示。
- キャンセルした場合は何も削除しません。
- 現行編成キー、旧編成キー、保存パーティーライブラリを削除します。

2. バージョン表記を一元化
- 正本は app-config.js の NIWARA_APP.version の1か所です。
- ヘッダー、編成メッセージ、状況コピー、PWA表示、Service Workerが同じ値を参照します。
- v9.1.6 / v9.1.5 の混在を解消しました。

3. モーダルのフォーカス管理
- 見せ合い、控え状態、技詳細、図鑑、ダメージ計算、素早さ比較、2人対戦の端末受け渡し画面を統一管理。
- 開いたらダイアログへフォーカス。
- Tab / Shift+Tab はダイアログ内で循環。
- 背景は inert + aria-hidden で操作不可。
- 閉じると、開く前に操作していたボタンへフォーカスを復元。
- Escで閉じられる通常モーダルを統一。端末受け渡し画面だけは秘密入力保護のためEscで閉じません。

4. 両者同時交代の順序
- A→B固定を廃止。
- 両者が通常交代を選んだ場合、交代前の実効すばやさで順序を決定。
- 同速はランダム。
- トリックルーム中は既存の行動順ルールに合わせて遅い側から。
- 順序は両者がまだ場にいる時点で確定し、最初の交代先の登場特性で再計算しません。

5. 保存パーティー名の安全な表示
- 対戦設定のパーティー選択肢を innerHTML の文字列連結で作る処理を廃止。
- createElement("option") + textContent に統一しました。

6. パッチ積み重ね構造を整理
- index.html から script.js → v6_patch.js → ... → v9_tools.js の多段読み込みを廃止。
- データは game-data.js、ゲーム本体は game.js に統合。
- game.js はprivate closure内で動作し、戦闘関数をグローバル空間へ大量展開しません。
- 旧 script.js 内で二重定義されていた関数宣言30個をASTで整理し、実際に有効だった最終定義だけ残しました。
- getModifiedStat は最終仕様を1実装へ統合しました。
- 新しい公開APIとして window.NIWARA を用意。旧 __PBV8 / __PBV9Tools は互換目的だけで残しています。
- 今後は新しい v10_patch.js 等を増やさず、game.js / game-data.js の該当モジュールを直接更新する前提です。

■ 保存データ互換
- 現在編成: niwaraBattleTeamV5
- 保存パーティー: niwaraBattlePartyLibraryV8

キーは変更していないため、同じGitHub Pages URLでv9系から更新する場合は通常そのまま引き継がれます。

ニワラバトル v9.1
====================

v9.0 PWA版を基盤に、対戦UI/研究ツールを大幅拡張した版です。

【主な変更】
1. 交代技の交代先選択タイミングを修正
   - 2人対戦でも、交代技を選んだ直後には交代先を決めません。
   - 実際に交代技が解決した時点で、それまでに起きた相手の通常交代や先行行動を確認してから交代先を選びます。
   - 交代技使用者が先に動いた場合は、交代先決定後に相手の選択済み行動が新しいポケモンへ続行されます。
   - CPU戦は既存のv6.3途中停止処理を維持します。

2. ニワラ図鑑
   - 全ポケモンを図鑑番号/名前で検索。
   - タイプ、分類、高さ、重さ、種族値、種族値合計を表示。
   - 特性名と説明を表示。
   - 覚える技をタイプ、分類、威力、命中、PP、効果付きで一覧表示。
   - ヘッダーおよび対戦画面からいつでも開けます。

3. ダメージ計算シミュレーター
   - 攻撃側/防御側の種族、特性、持ち物、性格、能力P、HP%、能力ランク、技、急所を設定可能。
   - ゲーム本体の calculateDamage() を利用して最小～最大ダメージと割合を表示。
   - タイプ半減きのみも反映。
   - 対戦中は「現在の対面を読み込む」で現在のA/Bを読み込み可能。
   - 対戦中の天候/フィールド等はゲーム本体の現在状態が計算に反映されます。

4. PWA更新
   - Service Workerを9.1.0へ更新。
   - v9_tools.jsをアプリシェルへ追加。
   - GitHub Pagesでは、従来どおりリポジトリのファイルをv9.1一式で置き換えれば更新可能です。

【保存データ】
v8/v9系と同じ localStorage キーを維持しているため、同じURLで更新する限り保存パーティーを引き継ぎます。

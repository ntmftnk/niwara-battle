ニワラバトル v13.0.2 修正パッチ
================================

対象: v13.0.1

■ 1. 環境研究AIの適応強化

v13.0.1までは、現在上位への対策加点はあるものの、実際の自己対戦結果を
構築・型選択へ戻す割合が弱く、試行回数を増やすほど固定ヒューリスティックの
癖へ収束しやすい状態でした。

v13.0.2では、研究中に得られた実績を次の構築へフィードバックします。

- 種族ごとの構築採用時勝率 -> 構築候補の評価
- 種族ごとの選出時勝率 -> 選出評価
- ポケモン別の技採用時勝率 -> 技構成生成
- ポケモン別の特性採用時勝率 -> 特性選択
- ポケモン別の持ち物採用時勝率 -> 持ち物選択
- ポケモン同士の実対面勝敗 -> 選出・メタ対策評価
- 現在の上位メタへの対策圧 -> 従来どおり併用

短期の偶然で型が固定されないよう、ベイズ平滑化と探索項を入れています。
また simulateRange 内でも1試合ごとにローカル環境を更新するため、同一バッチ内でも
直前までの結果を次の試合へ反映します。

旧v13研究データはそのまま読み込めます。
旧データに存在しない「技/特性/持ち物の採用時勝利数」は0から蓄積を開始します。

■ 2. わるあがき

シングル / ダブル / トリプル / 6vs6 / タッグ / 環境研究で仕様を統一しました。

- 使用可能PPがない時に候補になる
- 威力50の物理攻撃
- タイプ相性を受けず、ゴーストにも当たる
- PPを消費しない
- 使用後、最大HPの1/4相当の反動
- マジックガードでもわるあがき反動は防げない
- ノーマルタイプ半減きのみの対象にしない

CPUは、自分のPPが切れても「技を使える控え」があり交代可能なら控えへの交代を優先します。
チーム内に有効な交代先がない場合は、わるあがきを使用します。
これにより、PP0の技を無限に使用する問題とPP切れによる交代ループの両方を抑えます。

■ 3. デメリット技の研究評価

100万戦CSV監査で見つかった、基礎威力に対してデメリット評価が軽すぎる問題を追加修正しました。

- 次ターン反動技: 実効テンポを大きく減点
- 2ターン技: 即時発動条件がない場合は溜めターンを評価
- 自爆/自分ひんし技: 残HPが多いほど強く減点
- 最大HP反動技: 最大HP反動率を評価へ反映
- あばれ技: 継続拘束を評価へ反映
- みらいよち系: 即時威力技として扱わず、研究内でも遅延発動に変更

構築時の技評価と、実戦中の技評価の差を縮めています。

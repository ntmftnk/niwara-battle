ニワラバトル v13.0.5 修正パッチ
=================================
対象: v13.0.4（旧研究データの閲覧・途中再開も可能）
アプリバージョン: 13.0.5
Service Worker generation: 21

【1. 世代別の重み付き学習】
- 以前は終了した直近1世代の統計だけで learningStats を置き換えていました。
- 新方式では、最新世代に45%、過去の重み付き統計に55%を配分するEMAに変更しました。
- 各世代の試合数が異なる場合は、まず試合数で正規化します。
- 採用数・勝利数・技・特性・持ち物・性格・基礎ポイント・種族対面・型対面・KO/ダメージなどを同じ基準で平滑化します。
- 直近の一世代分の実績を過剰に増幅させないよう、best-responseの構築・特性・技への追加点を一律約14%緩和しました。
- 世代同期バリア、世代ごとの生データ・累積統計・詳細区間スナップショットは維持しています。
- 変更された学習データは次世代から適用されます。ゲーム中の対戦ルール自体は変更しません。

実効世代重み（開始後十分な世代がある場合）:
 最新世代 45%、1世代前 24.75%、2世代前 13.6125%、3世代前 7.4869%…
 直近以外の古い履歴も指数的に減衰しながら残ります。

【2. 性格・基礎ポイントをポケモンごとに集計】
- 各ポケモンの「性格」「基礎ポイント H/A/B/C/D/S」「性格＋基礎ポイント」の採用数を別々に記録します。
- 各項目の構築勝利数・構築勝率を追加し、型選択に小さくフィードバックします。
- ポケモン別の詳細表から技・特性・持ち物に加えて性格・配分を確認できます。
- 従来の「よく使われる性格・能力P」表も選択したポケモンのみを表示し、採用率・構築勝率を併記します。
- CSV出力に species_nature / species_base_points / species_nature_points の累積行と
  snapshot_species_nature / snapshot_species_base_points / snapshot_species_nature_points の区間行を追加しました。
- JSONに同じ情報をポケモンごとの species[*] と snapshots[*].stats.species[*] として保存します。
- 従来の CSV 冒頭7列と種族別技・特性・持ち物・詳細スナップショット行は維持します。

【3. 旧研究データについて】
- v13.0.4以前の保存データも読み込めます。既存の「種族＋性格＋基礎ポイント」採用数から、
  各種族の性格・配分別の採用数を再構成します。
- 旧データに存在しない性格・配分ごとの勝利数は復元できないため「-」として表示し、CSVでは空欄にします。
- v13.0.3以前のスナップショットで詳細統計が記録されていない区間も復元できません。
- 途中研究を再開すると、保存済みの直前学習統計を初期値として、その後からEMA更新が始まります。
  過去の各世代をさかのぼって再重み付けすることはできません。
- v13.0.5の学習挙動を正しく評価するには新しい研究を開始してください。
- 10万戦の周期が改善したかは、複数シードで実測確認が必要です。

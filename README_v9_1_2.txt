ニワラバトル v9.1.2

■ 主な修正
スマホ/PWAで図鑑・ダメージ計算ツールを開いた際のモーダル操作不具合を再修正しました。

1. iOS/PWAでのモーダル位置ずれ修正
- v9.1.1で採用した body { position: fixed; top: -scrollY } 方式を廃止。
- utility modal自体を viewport 全面の fixed レイヤーとして表示。
- スマホではカードを画面全面に固定し、safe-area内へ内容を配置。

2. 背景スクロール透過の修正
- html/bodyのoverflowをロック。
- documentレベルでtouchmove/wheelを監視し、図鑑・ダメージ計算のスクロール領域以外へスクロールを連鎖させないよう変更。
- モーダル端までスクロールした後も、背後の通常画面へスクロールが抜けないようにしています。

3. 閉じるボタンを常時操作可能に
- ヘッダーをスクロール本文から分離。
- 図鑑本文だけを専用スクロール領域に変更。
- 閉じるボタンはスクロールしても画面上部に残ります。
- iPhoneのsafe-areaを考慮。

4. スマホで図鑑検索欄を自動フォーカスしない
- v9.1.1までは図鑑を開いた直後に検索欄へfocusしていました。
- iOSでキーボード表示とVisual Viewport移動が発生し、位置ずれを悪化させるため、スマホでは廃止。
- 検索したい場合だけ検索欄をタップしてください。

5. ダメージ計算ツールにも同じモーダル修正を適用

■ PWA更新
APP_VERSION / Service Worker cache versionを 9.1.2 に更新しています。
GitHub Pagesへファイルを上書き後、アプリ内の「更新確認」→新版通知→「今すぐ更新」で切り替えてください。

ニワラバトル v12.0.4 修正パッチ
================================

v12.0.3 に対する累積差し替えパッチです。
ZIPを解凍し、中の同名ファイルをGitHub Pagesの既存リポジトリのルートへ上書きしてください。

■ 今回の主な修正

1. 溜め技 / あばれ状態での交代禁止
- シングルと非シングルの両方で対応。
- エレクトロビーム、メテオビーム、ソーラービーム、ゴーストダイブ、あなをほる、各種「さけび」、せいしんとういつ等の溜め中は通常交代できません。
- 1ターン目にPPを消費して溜め状態へ入り、2ターン目は同じ技を強制実行します。
- パワフルハーブ、晴れ時ソーラービーム、雨時エレクトロビームは即時処理。
- げきりん、あばれる、はなびらのまい、ふんがいは2～3ターン同じ技を強制し、その間は通常交代できません。
- あばれ技は最初の使用時だけPPを消費し、終了後にこんらんします。
- 人間操作だけでなくCPUの交代判断にも同じ制限を適用。

2. かふんだんご
- ダブル / トリプル / タッグで隣接する味方も対象に選択可能。
- 相手へ使う場合は従来どおり威力90の攻撃。
- 味方へ使う場合は攻撃せず、最大HPの1/2を回復。
- まもる、かいふくふうじ等の既存状態を考慮。
- トリプルは既存の隣接判定を維持。

3. 図鑑のフォルム違い
- formsデータを持つポケモンの詳細に「フォルム」欄を追加。
- 各フォルムの名称 / 高さ / 重さ / H-A-B-C-D-S / 合計種族値を表示。
- 図鑑リストにも「○フォルム」と表示。
- フォルム名でも図鑑検索可能。
- 同一種族のフォルムを別図鑑番号として水増しせず、同じ詳細画面内にまとめます。

4. 技を1～4個で編成可能
- 技1は必須。
- 技2 / 技3 / 技4に「選択しない」を追加。
- 保存・読込・テキストインポート・対戦生成は1～4技に対応。
- 旧4技編成データとの互換性を維持。

■ これまでの修正も累積
- 非シングル選出画面の排他表示 / 編成へ戻る時の二重表示防止
- 非シングルの選出詳細・見せ合い確認・控え状態確認
- ねばねばネット / どくびし / あつぞこブーツ等の修正
- 発動済み特性の公開
- 非シングルの詳細ログ
- こおり状態の行動不能
- ハロウィンパンク同一ターン上昇/下降競合防止
- PWA更新中の非シングル対戦判定

■ 1. アイアンローラー
- フィールドが存在しない時はライブ対戦でも研究でも使用不能として評価。
- 非シングル実戦処理もフィールド無しなら失敗し、ダメージを与えない。
- フィールド有りなら通常候補へ戻る。
- 成功時はフィールドを解除。
- 自力でフィールドを用意できない構築では、構築時の静的評価も大幅に下げる。

■ 2. AIの技評価を横断監査
基礎威力だけで評価すると過大/過小になりやすい以下を共通評価へ反映しました。

条件成立が必要な技：
- フィールド必須（アイアンローラー）
- 登場直後限定
- 相手の持ち物必須
- ふいうち系 / はやてがえし系
- 2ターン技 / あばれ技

期待値補正：
- 命中率
- 2～5回技の期待ヒット数（通常は期待3回）
- 固定ダメージ / いかりのまえば / がむしゃら / いのちがけ
- カウンター / ミラーコート / メタルバースト
- 一撃技

可変威力：
- くさむすび / けたぐり
- ヘビーボンバー
- ジャイロボール
- ハードプレス
- きしかいせい
- アシストパワー
- はきだす
- ウェザーボール
- れんぞくぎり / ころがる / ふくろだたき
- 状態異常時・被ダメージ時・前技失敗時・持ち物なし等の条件倍化技

特殊なダメージ参照：
- ボディプレス / パンプキンプレス（自分の防御で攻撃）
- サイコショック（相手の防御を参照）
- ビーラインビーム（いまひとつ時の補正）

シングルCPU、非シングルCPU、環境研究の3系統を合わせています。

■ 3. ソルジエンド
v12.0.5の研究コアでは、ソルジエンドのフォルム性能が研究戦闘へ反映されず、
ソロフォルムの低い攻撃性能のまま選出評価されていました。

v12.0.6では：
- ぎょぐん：HP条件で school / solo を研究戦闘へ反映
- スワームチェンジ：HP1/2以下で perfect を反映
- フォルム別種族値を実数値へ反映
- 構築時の物理アタッカー判定、性格・能力P、技構成を能力に合わせて評価

同一シード・シングル180戦の実測：
- v12.0.5：構築86 / 選出0（0.0%）
- v12.0.6：構築128 / 選出20（15.6%）

■ 4. エンプレイス
v12.0.5では、ナイトスケイルの特攻2倍が研究ダメージ計算へ入っていませんでした。

v12.0.6では：
- ナイトスケイルの特殊攻撃性能を研究ダメージ計算へ反映
- 構築・選出評価にも特攻倍率を反映
- ちょうのまい等のセットアップ技を4攻撃より優先できる構築ロジックへ補正
- ライブ非シングル側のダメージ計算にもナイトスケイルを反映

同一シード・シングル180戦の実測：
- v12.0.5：構築107 / 選出0（0.0%）
- v12.0.6：構築101 / 選出24（23.8%）

■ 5. アイアンローラー研究実測
同一シード・シングル180戦：
- v12.0.5：セット採用353 / 実戦使用106
- v12.0.6：セット採用0 / 実戦使用0

このテスト環境では自動構築に安定したフィールド供給がないため0になっています。
フィールドが存在する実戦状態ではライブCPU評価が通常候補へ戻ることを別途確認しています。

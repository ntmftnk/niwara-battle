ニワラバトル v10.1.2

v10.1.1 を基礎に、CPU AIの実戦学習・ため技判断・CPU vs CPU完全自動進行を修正したリリースです。

■ CPU AI: 実測ダメージ記憶
CPUは、自分のポケモンが実際に受けた攻撃について、
「受けた自分の個体 × 相手種族 × 使用技」ごとに実ダメージ率を戦闘中だけ記憶します。

記憶するのはCPU自身が対戦中に観測できた情報だけです。
相手の未公開性格・能力P・未公開技・未公開特性・未公開持ち物・未登場控えは参照しません。

同じ相手・同じ技を再び受ける可能性がある場合、タイプ相性による机上予測だけでなく、
直近値・平均値・最大観測値を交代先評価へ反映します。
特に「前回46%受けた / 現在HP43%」のような候補は、非常に強いAIではほぼ致死交代として大きく減点されます。

能力ランクが変化している場合は、公開されている攻撃側ランクと自分側ランクの差を使って観測値を補正します。

■ CPU AI: 2ターンため技
パワフルハーブが消費済み、かつ天候による即時化もない2ターン技は、
「このターンにダメージを出せる技」として評価しなくなりました。

メテオビーム等では、次の相手攻撃を受ける前提で生存余裕を評価します。
前に同じ相手から受けた実測ダメージが現在HP以上なら、非常に大きなマイナス補正を掛けます。
そのため、残りHPが少ない状態でパワフルハーブ消費後のメテオビームを選び続ける挙動を抑制します。

■ CPU vs CPU
CPU vs CPUではプレイヤーの6→3選出操作を要求しません。
モード画面で「CPU同士の対戦を開始」を押すと、
CPU A/Bがそれぞれ
  自動構築（設定時）→ 6→3自動選出 → 先発決定 → 対戦開始
まで自動で進みます。

また次ターンの自動予約を、ターン解決が完全に終了した後に行うよう変更しました。
これにより1ターン目の後に自動進行が止まる経路を修正しています。
一時停止 / 再開 / 1ターン進める / 進行速度は従来どおり利用できます。

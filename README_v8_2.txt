ニワラバトル PB_v8.2
====================

主な追加・修正

1. タイプ半減きのみを実装
- オッカのみ（ほのお）
- イトケのみ（みず）
- ソクノのみ（でんき）
- リンドのみ（くさ）
- ヤチェのみ（こおり）
- ヨプのみ（かくとう）
- ビアーのみ（どく）
- シュカのみ（じめん）
- バコウのみ（ひこう）
- ウタンのみ（エスパー）
- タンガのみ（むし）
- ヨロギのみ（いわ）
- カシブのみ（ゴースト）
- ハバンのみ（ドラゴン）
- ナモのみ（あく）
- リリバのみ（はがね）
- ロゼルのみ（フェアリー）
- ホズのみ（ノーマル）

ホズのみ以外は、そのタイプの「こうかばつぐん」の攻撃を受ける時だけ発動します。
ホズのみはノーマルタイプの攻撃を受ける時に発動します。
発動したきのみは消費され、ダメージを半減します。
連続技では最初の該当ヒットだけ半減し、その後は消費済みになります。
みがわりが攻撃を受けた場合は発動しません。
みらいよちの着弾時にも、本体が攻撃を受ける場合は発動します。
マジックルーム中は既存の持ち物無効仕様に従って発動しません。

2. 見せ合い画面に観戦視点 / 神視点を追加
- 選出者視点: 従来どおり、自分の完全情報 + 相手の見せ合い公開情報。選出操作可能。
- 観戦視点: A/B双方の種族・タイプのみを表示。選出操作不可。
- 神視点: A/B双方の技・特性・持ち物・実数値を含む完全情報を表示。選出操作不可。
- 選出操作へ戻る場合は「選出者視点」に戻します。

3. 対戦中の「見せ合いを確認」を強化
- A視点 / B視点: 相手側の見せ合い公開情報のみ。
- 観戦視点: 両者の見せ合い公開情報。
- 神視点: 両者の技・特性・持ち物・実数値を含む完全情報。
- 選出した3匹・選出順は神視点でも見せ合いモーダルには表示しません。

4. 控えポケモンのHP%表示
相手側のポケモンが一度場に出て公開済みになり、その後控えへ戻った場合、
チーム表示に現在HPを整数%で表示します。
未登場の相手ポケモンは従来どおり「???」です。

5. 発動告知される特性の公開情報
フェアリーオーラが場に出た時に
「○○の フェアリーオーラが発動した！」
とログへ表示され、以後その特性を公開済みとして扱います。
あめふらし・すなおこし・トリックビルダー等、既にログ表示される特性は従来どおりです。

6. 公開情報判定の誤公開を修正
ログに特性名・持ち物名が出た際、同じ特性/持ち物を持つ別の控えまで公開される可能性があったため、
「ポケモン名 + 特性名/持ち物名」の両方がログに出た個体だけを公開するよう修正しました。

互換性
- 保存パーティーのキーは v8 系と同じ niwaraBattlePartyLibraryV8 を継続使用します。
- v8.1.1 の保存パーティーをそのまま利用できます。

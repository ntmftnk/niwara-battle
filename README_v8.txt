ニワラバトル PB_v8

主な追加機能
- 保存パーティーを最大30個まで名前付きで保存
- 保存済みパーティーをプレイヤー側・CPU側のどちらにも指定可能
- 対CPU戦 / 同一端末2人対戦（ホットシート）
- プレイヤーA視点 / プレイヤーB視点 / 観戦視点 / 神視点
- 視点に応じた技・特性・持ち物・実数値・HP数値・ログの情報制限
- 延長アイテム由来の天候/壁/フィールドの残りターン秘匿
- 強化CPU AI
- 強化ランダム構築生成
- CPUによる6匹から3匹の選出評価

2人対戦
同じPC・スマートフォンを交互に操作する方式です。
Aが行動を決めた後、画面を隠す案内を挟んでBへ端末を渡します。
Bの入力完了後に両者の行動を解決します。

4視点
A視点: Aの自分情報は詳細表示。B側の未公開情報は隠します。
B視点: Bの自分情報は詳細表示。A側の未公開情報は隠します。
観戦視点: バトル中に公開された情報だけを表示します。
神視点: 両者の実数値・技・特性・持ち物・HP数値などをすべて表示します。

公開情報について
- 相手/観戦側のHPは具体的数値を出さずHPゲージで表示します。
- 使用した技は公開済み技として記録します。
- 発動ログ等で判明した特性・持ち物は以後公開します。
- 延長アイテムによる8ターン効果は、相手側では最初は通常5ターン相当のカウントに見えます。
  延長が実戦上判明した時点、または原因となる持ち物が公開された時点で実残りターンを表示します。

強化CPU
- 期待ダメージ、命中、KO、先制技、タイプ相性を評価
- 回復、積み、壁、設置技、追い風、トリックルーム等を状況評価
- 不利対面では控えへの交代も評価
- 反動/行動不能ターンを伴う技もデメリットとして評価
- 6匹から3匹の選出も相手との対面相性を比較して決定

強化ランダム構築
- 6匹の種族重複なし、持ち物重複なし
- 物理/特殊、素早さ、耐久、弱点の集中を評価
- 特性と持ち物の相性を考慮
- 特性と技の相性（きれあじ、ちからずく、ポイズンヒール等）を考慮
- 同タイプ技だけになりにくいよう技範囲を評価

注意
- 2人対戦はオンライン通信ではなく、同一端末で遊ぶローカル対戦です。
- 神視点は検証・観戦用です。対戦者が使用すると非公開情報も見えます。
- これまでのPB_v7_2はバックアップとして残すことを推奨します。

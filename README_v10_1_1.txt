ニワラバトル v10.1.1
====================

v10.1.0 を基礎に、PWA更新検出と反動・反動ターン・自爆・失敗時ダメージ系を横断修正した保守リリースです。
保存パーティー用 localStorage キーは従来と同一です。

1. PWA更新検出
---------------
- app-config.js のバージョンを 10.1.1 に更新。
- sw.js 自体のトップレベル内容にも更新世代を持たせ、旧PWAから service worker 更新を検出しやすくしました。
- pwa.js は配信元の app-config.js を一意なクエリ + cache:no-store で直接確認します。
- 配信版と現在版が異なる場合、`sw.js?release=<version>` として版付きURLでService Workerを再登録します。
- 「更新確認」は通常の registration.update() だけに依存しません。

2. ギガインパクト等の反動ターン
-------------------------------
対象: ギガインパクト / はかいこうせん / ハードプラント / ブラストバーン / ハイドロカノン
- 攻撃成功後の次ターンは行動不能。
- 反動ターン中は通常交代を選べません。
- 反動ターンは技PPを消費しません。
- ほえる等で強制的に場を離れた場合、反動待ち状態は交代先・再登場時へ持ち越しません。
- 外れ・まもる・無効化など攻撃が成功しなかった場合は反動ターンを付与しません。

3. 与ダメージ比例の反動
------------------------
対象: フレアドライブ / ウッドハンマー / ワイルドボルト / ウェーブタックル / すてみタックル / ボルテッカー / ビーストダッシュ / ソウルバースト
- 実際に削ったHP量を基準に反動を計算。
- 端数処理を「四捨五入（0.5切り上げ）」へ修正。
- 最低1ダメージ。
- みがわりを削った場合は実際にみがわりから失わせたHPを基準にします。
- マジックガード時は通常反動を受けません。

4. わるあがき
-------------
- v10統合後の最終 useMove 経路から反動処理が抜けていた問題を修正。
- 最大HPの1/4を四捨五入（0.5切り上げ）して反動ダメージ。
- マジックガードでもわるあがき反動は受けます。

5. 最大HP基準・失敗時ダメージ
------------------------------
- てっていこうせん: 最大HPの1/2、端数切り上げ。命中失敗・まもる・無効でも使用コストを受ける。マジックガードなら無効。
- サンダーダイブ: 攻撃失敗時に最大HPの1/2、端数切り捨て。マジックガードなら無効。

6. 自爆系
---------
対象: だいばくはつ / ミストバースト
- 使用後は、まもる・タイプ無効・命中失敗等でも使用者がひんしになります。
- しめりけで技そのものが不発になった場合はひんしになりません。

GitHub Pages 更新方法
--------------------
v10.1.0 からは全削除不要です。ZIPを解凍し、中身をリポジトリのルートへ上書きアップロードしてください。
アップロード後、ゲームの「更新確認」を押してください。
今回のv10.1.1では旧更新経路から抜け出せるよう sw.js 自体も変更しています。

主要ファイル:
- app-config.js
- game-data.js
- game.js
- pwa.js
- sw.js
- index.html / style.css

ニワラバトル v12.0.1 差し替えパッチ
====================================

対象: v12.0.0
適用: このフォルダ内のファイルを既存リポジトリのルートへ上書きしてください。
      icons/、game-data.js、index.html、manifest.webmanifest 等は既存のものをそのまま使用します。

変更ファイル
- app-config.js
- game.js
- format-engine.js
- pwa.js
- sim-core.js
- style.css
- sw.js

主な修正
1. 追加バトル形式の画面遷移
- builder / mode / selection / battle / format battle / research を排他的に表示するよう修正。
- タッグ選出中に「編成へ戻る」を押した際、編成画面と選出画面が重なる問題を修正。
- ヘッダーから編成へ戻った際にformat-engine側のstate/selection session/autoplay timerも破棄。
- PWA更新判定で、ダブル・トリプル・6vs6・タッグの選出/対戦中も「対戦中」として扱う。

2. タッグ/非シングル選出UI
- 選出中はバトル用フィールド・ログ・観戦UIを隠した専用表示へ変更。
- 自分の6匹、相手の見せ合い、選出順を明示。
- タッグ4人の人間操作を順番に処理し、端末受け渡し画面を維持。

3. ねばねばネット / 設置技
- ねばねばネットをシングル・ライブマルチ・環境研究コアへ接続。
- 接地判定、ひこう/ふゆう/ふうせん/でんじふゆう/うちおとす/ねをはるを考慮。
- あつぞこブーツで設置技効果を無視。
- クリアボディ/しろいけむり/クリアチャーム/しろいきりによる能力低下防止を反映。
- かちきの能力低下反応を反映。
- マジックガードは設置ダメージを防ぐが、ねばねばネットの能力低下自体は防がない。
- 接地したどくタイプは、あつぞこブーツ所持時でもどくびしを除去。
- こうそくスピン/きりばらい/場の除去効果でねばねばネットも除去。

4. 非シングル戦闘メカニクス監査で修正した主な差分
- 複数対象/隣接/位置、交代・ひんし交代、交代技の解決途中選択。
- ひらいしん/いかりのこな系の引き寄せ、ビビッドボディ、しめりけ、ぼうおん、かざぐるま等。
- みがわり、各種フィールド、ルーム、壁、設置技、遅延攻撃、位置単位のねがいごと。
- こんらん、かいふくふうじ、ポイズンヒール、たいねつ、うちおとす等の状態/ターン末処理。
- てだすけを複数人戦で重ねられるようにし、未使用分はターン終了時に消去。
- まもる系連続成功率、トリックルーム/マジックルーム/ワンダールームの再使用解除。
- CPU公開情報境界は維持し、相手の未公開set情報を直接参照しない。

バージョン
- app-config.js: 12.0.1

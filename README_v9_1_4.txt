ニワラバトル v9.1.4
====================

v9.1.3を基にした更新版です。

主な変更
--------
1. ダメージ計算ツール
- 持ち物欄の先頭付近に「なし」を明示追加。
- 対戦中の公開情報保護はv9.1.3の仕様を維持。

2. 素早さ比較ツール
- ヘッダーと対戦中のツール欄から開けます。
- 「基準：抜きたいポケモン」に、ポケモン・特性・持ち物・性格・S能力P・Sランク・まひ・おいかぜを指定。
- 「比較：抜きたい側」に、ポケモン・特性・持ち物・Sランク・まひ・おいかぜを指定。
- 上昇補正 / 無補正 / 下降補正の3区分について、基準の実効Sを1以上上回る最小S能力P（0～32）を表示。
- 32でも抜けない場合は、その旨と最大時の実効Sを表示。
- こだわりスカーフを反映。
- かそく、かざぐるま等で既に上がった分はSランク欄で指定して再現。
- 対戦中は「現在の対面を読み込む」に対応。相手側の性格・S能力P・未公開特性/持ち物は取得しません。

3. 公開情報 / 状況＋ログコピー監査
- 同名ポケモンが両軍にいる場合、ログ中の名前だけで「登場済み」と判定していた問題を修正。
- 登場済み判定は、実際に場へ出たPokemonオブジェクトへ直接付与する方式に変更。
- これにより、相手先発とこちらの未登場控えが同名でも、未登場控えが相手視点のチーム表示や状況コピーに出ません。
- 特性/持ち物の公開判定も、同名個体が複数いる場合は場にいる一致個体を優先し、それでも曖昧なら非公開側へ倒すよう変更。
- A/B視点：自分側の非公開情報のみ。相手の未登場控えは???。
- 観戦視点：両者とも公開情報のみ。
- 神視点：仕様どおり完全情報。
- 見せ合いコピーも、A/Bでは自分側のみ完全情報、相手側は見せ合い公開情報のみ。観戦は公開情報、神視点は完全情報。

ニワラバトル v9.1.3

変更点
1. ダメージ計算ツールの対戦中読み込みを公開情報準拠へ変更
   - 自分側は能力P・性格・特性・持ち物・技を反映。
   - 相手側はHP%、能力ランク、公開済み特性/持ち物/技だけを反映。
   - 相手の能力P・性格・未公開特性/持ち物/技は取得しない。
   - 未公開特性/持ち物/性格は空欄にして、計算時に仮定を選択する。
2. ダメージ計算に「攻撃側 ↔ 防御側」ボタンを追加。
3. ドルピカの習得技から「ばくおんぱ」を削除。
4. PWAキャッシュバージョンを9.1.3へ更新。

GitHub Pages更新
ZIPを解凍し、リポジトリ直下へ中身を上書きアップロードしてください。Pages設定は変更不要です。

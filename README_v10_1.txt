ニワラバトル v10.1.0
================================

v10.0.0 の統合ランタイムを土台に、CPUシステムを大幅強化した版です。

■ CPU難易度
対CPU戦では「普通 / 強い / 非常に強い」を選択できます。
難易度は、構築・6→3選出・対戦中の行動判断すべてに反映されます。

普通
- 軽い候補探索と大きめの判断ゆらぎ。
- 交代判断は控えめ。
- CPU構築は役割を意識しつつ、上位候補からある程度ランダムに選択。

強い
- 見せ合い6匹、公開済み技、公開済み特性/持ち物、HP%、状態異常、能力ランク、場を考慮。
- 交代先の攻守相性、被ダメージリスク、回復・積み・設置技などを評価。
- 6→3選出は相手6匹への相性行列から組み合わせを探索。

非常に強い
- 相手の未公開情報を直接読むのではなく、種族が取り得る技・特性・耐久配分を複数仮定して評価。
- 未公開技については「その種族が覚え得る有力技」として警戒し、公開済み技は確度を上げて扱います。
- 交代読みとして、見せ合い6匹の未登場候補に対する技の通りも評価します。
- 構築では攻撃範囲、物理/特殊バランス、素早さ、耐久、先制技、交代技、回復、設置技、速度操作、弱点集中などを評価して多数候補から選びます。

■ AIが参照しない非公開情報
AI判断専用の公開情報スナップショットを設けています。
相手について以下は直接参照しません。
- 実際の性格
- 実際の能力P
- 未公開の特性
- 未公開の持ち物
- 未公開の採用技
- 相手の正確なHP/最大HP（公開HP%のみ使用）
- 相手がそのターンに選択済みの行動
- まだ登場していない選出3匹の正体

未公開情報については、見せ合いで公開された種族情報とゲーム内データから「あり得る候補」を仮定して判断します。

■ CPUが担当できる範囲
- 6匹構築
- 6匹から3匹の選出・先発決定
- 技選択
- 通常交代
- 交代技の交代先
- ひんし時の次ポケモン

■ CPU vs CPU
対戦形式に「CPU vs CPU（観戦）」を追加しました。
CPU A/Bそれぞれについて、
- 強さ
- 自動構築または保存パーティー
を選べます。

両CPUが構築・選出・対戦をすべて自動実行します。
対戦中は、
- 一時停止 / 再開
- 1ターン進める
- 進行速度（ゆっくり / 標準 / 速い）
を操作できます。

観戦・A/B視点・神視点、図鑑、ダメージ計算、素早さ比較、状況＋ログコピーなど既存ツールは引き続き利用できます。

■ PWA更新
app-config.js のバージョンは 10.1.0 です。
GitHub Pagesではv10.1.0の中身を既存リポジトリへ上書きアップロードしてください。
Service Workerはバージョン値から新しいキャッシュを作成します。

ニワラバトル v8.3
==================

■ v8.3 追加内容
・編成画面に「テキストフォーマットで編成を入出力」を追加。
・6匹分のフォーマットを貼り付けて、現在の編成へ一括反映できます。
・「現在の編成をコピー」で、現在の6匹を同じ形式へ書き出してクリップボードへコピーできます。
・「空フォーマットをコピー」で、新規入力用テンプレートをコピーできます。
・ポケモン、特性、持ち物、技は日本語名または内部IDで指定できます。
・入力時に、種族、特性、持ち物、性格、能力ポイント、習得技、Species Clause、Item Clauseを検証します。
・不正な入力は編成を変更せず、何匹目のどの項目が不正かを表示します。

■ フォーマット
# ニワラバトル編成フォーマット v1
[1]
ポケモン: ウルフレム
特性: きれあじ
持ち物: いのちのたま
性格: ようき
能力P: H=0 A=32 B=0 C=0 D=2 S=32
技: かえんざん / じしん / インファイト / つるぎのまい

[2]
...以下6匹目まで同形式

・[1]～[6]で6匹を区切ります。
・技は「/」区切りで4つ指定します。
・能力Pは H/A/B/C/D/S をすべて指定します。
・能力Pは各0～32、合計66以下です。
・反映しただけでは保存パーティーへ自動保存されません。必要に応じて既存の保存ボタンで保存してください。

■ 互換性
v8.2.1までの機能をそのまま引き継ぎます。
保存パーティーのlocalStorageキーも変更していません。

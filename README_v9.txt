ニワラバトル v9.0
===================

v8.4までの対戦機能を維持したまま、PWA対応を本格導入したメジャーアップデートです。

■ v9.0の主な追加
- PWAインストール対応（Android/PCの対応ブラウザ、iPhone/iPadはSafariの「ホーム画面に追加」）
- 一度オンラインで読み込めば、主要ファイルをアプリシェルとして保存してオフライン起動可能
- Service Workerによるバージョン単位のアプリシェル固定
- 新版は待機状態で準備し、「今すぐ更新」を押した時だけ一括切替
- 対戦中は「今すぐ更新」を無効化し、対戦途中のコード差し替えを防止
- 起動時/画面復帰時/手動ボタンで更新確認
- オンライン/オフライン状態をヘッダー表示
- iPhoneのノッチ/ホームインジケータ用Safe Area対応
- スマホ向け48px級タップ領域、フォーム拡大防止、対戦カード/技/交代UI最適化
- manifest + 192/512/maskableアイコン

■ 従来どおりのアップデート運用
PC側では今までどおり、公開先のフォルダを新版一式で置き換えて構いません。
新版のsw.jsがブラウザに検出されると、新版ファイルは別キャッシュへまとめて準備されます。
ユーザーが「今すぐ更新」を押すまでは、現在プレイ中の旧版がそのまま動きます。

■ 重要
PWA機能にはHTTPSまたはlocalhostが必要です。file://でindex.htmlを直接開いた場合、ゲーム本体は従来どおり動きますが、インストール/Service Worker/オフラインキャッシュは利用できません。
保存パーティーのlocalStorageキーはv8系から変更していないため、同じ公開URL（origin）を維持すればそのまま引き継がれます。

■ 公開
GitHub Pages / Cloudflare Pages / Netlify / Vercelなどの静的ホスティングへ、このフォルダの中身をそのまま配置できます。

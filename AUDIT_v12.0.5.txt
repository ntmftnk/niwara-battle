3. 強い制限条件テスト
---------------------
使用可能条件:
- ポケモン: 先頭6種のみ
- 技: その6種から指定した少数技のみ
- 特性: 指定した特性のみ
- 持ち物: なし / たべのこし / オボンのみ相当の3候補

各20戦:
- シングル: 指定外 species/moves/abilities/items = 0
- ダブル: 指定外 species/moves/abilities/items = 0
- トリプル: 指定外 species/moves/abilities/items = 0
- 6vs6: 指定外 species/moves/abilities/items = 0
- タッグ: 指定外 species/moves/abilities/items = 0

4. 1技だけの制限
-----------------
6ポケモンそれぞれに合法技が1つしか残らない条件でも研究を実行できることを確認。
v12.0.4で導入した1～4技構成と整合します。

5. 持ち物制限
-------------
- 「持ち物なし」だけ許可: 研究実行 OK
- 「持ち物なし」禁止 + 実物持ち物6種: 研究実行 OK / 指定外持ち物0
- 「持ち物なし」禁止 + 実物持ち物5種以下: 事前検証エラー

6. 構築不能条件
---------------
使用可能ポケモンを5種にした条件を validateConfig に投入し、
「構築可能なポケモンが5種。6種以上必要」のエラーになることを確認。
技/特性の制限によって実質構築不能になった種も同じ判定から除外されます。

- 10戦 + 10戦を mergeStats
を比較し JSON 完全一致。

実際には使用禁止の技を、制限環境のCPUだけが仮想的な脅威として評価する不整合を防止。

ニワラバトル v9.1.1

モバイルPWAで図鑑・ダメージ計算モーダルを開いた際の操作性を修正。

修正内容
- 図鑑/ダメージ計算を開いている間、背景ページのスクロール位置を固定。
- iOS/ホーム画面PWAでも背景のスクロール抜けを防止。
- 閉じるボタンをモーダル上部にsticky固定。
- ノッチ/ステータスバーを考慮したsafe-area余白を追加。
- モバイルではツールを100dvhの全画面表示にし、ツール内部だけスクロール。
- オーバースクロールの背景への伝播を抑止。
- PWAキャッシュバージョンを9.1.1へ更新。

既存の保存パーティー(localStorage)は変更しません。
GitHub Pagesではv9.1.1の中身を既存ファイルへ上書きアップロードしてください。

ニワラバトル v12.0.2 UI parity patch
=====================================

v12.0.1 へ上書きする差し替えパッチです。

変更内容
--------
1. 非シングル選出画面をシングル相当に拡張
   - 自分の6匹: 種族/タイプ/特性/持ち物/性格/能力P/実数値/4技を表示
   - 技名ボタンから既存の技詳細を開ける
   - 相手の6匹: 見せ合い公開情報（種族/タイプ）のみ表示
   - タッグ: 味方トレーナーの見せ合いも完全情報で確認可能
   - 選出順をカード上に表示

2. 非シングル対戦画面にシングル相当の確認機能を追加
   - 「見せ合いを確認」
   - 「控え状態を確認」

3. 見せ合い確認の公開情報ルール
   - 自分視点: 相手側の見せ合い6匹（タッグは相手2トレーナー分）を公開情報のみ表示
   - 観戦視点: 両側の見せ合いを公開情報のみ表示
   - 神視点: 全参加者の完全情報を表示
   - 選出内容・選出順は表示しない

4. 控え状態確認の公開情報ルール
   - 自チーム: HP実数、状態、ランク、特性、持ち物、実数値、技とPP
   - 相手未登場控え: ???
   - 相手登場済み控え: HP%、状態、ランク、公開済み特性/持ち物/技
   - 神視点: 両側完全情報
   - タッグではトレーナー単位で控えを分けて表示

5. バージョン
   - app version: 12.0.2
   - Service Worker updater-generation: 10

上書き対象

- app-config.js
- index.html
- format-engine.js
- style.css
- sw.js

ニワラバトル v9.0 PWA 公開・更新手順
=====================================

1. HTTPS対応の静的ホスティングへ、niwara_battle_v9 フォルダの「中身」を配置します。
   GitHub Pages / Cloudflare Pages / Netlify / Vercel 等で利用できます。

2. スマホで公開URLを開きます。
   Android/PC: 対応ブラウザの「アプリをインストール」
   iPhone/iPad: Safari → 共有 →「ホーム画面に追加」

3. 初回オンライン読み込み後、ゲーム本体一式がキャッシュされます。
   以後は通信が無い状態でも起動できます。

【次回アップデート時】
- 今までどおり公開先のファイル一式を新版へ置き換えてください。
- 新版では sw.js の APP_VERSION / CACHE_NAME も新版へ更新されたものを必ず一緒に配置します。
- 旧版を開いているユーザーには「新しいバージョンがあります」と表示されます。
- 「今すぐ更新」を押すまでは旧版一式のまま動くため、新旧JSの混在を防げます。
- 対戦中は更新適用ボタンが無効になります。
- 更新適用後に自動再読み込みされ、新版へ切り替わります。

【保存パーティー】
localStorageは公開URLのorigin単位です。同じドメイン・プロトコル・ポートを維持してください。
ゲーム側の保存キー niwaraBattlePartyLibraryV8 は互換性のためv9でも変更していません。

【注意】
file://でindex.htmlを直接開く方式ではService Workerは動きません。
PCでローカル確認する場合、PWA機能まで試すにはlocalhostのHTTPサーバーを使用してください。

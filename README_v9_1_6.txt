ニワラバトル v9.1.6

主な変更
- PC版で「素早さ比較」が開けない環境向けに、起動イベントをdocument委譲方式へ変更。
  ヘッダーと対戦中の両ボタンが同一の openSpeed() 経路を通ります。
- PWAキャッシュバージョンを9.1.6へ更新。PCだけ古いv9_tools.jsを保持する状態を解消しやすくしました。
- スマホ/PWAの上部ヘッダーを大幅に省スペース化。
  タイトル＋バージョンを1段目、各ツールを横スクロール1段に配置します。
- 対戦中の視点ボタンと、見せ合い/控え/ログコピー/図鑑/ダメージ計算/素早さ比較のツール群も横スクロール式へ変更。
- v9.1.5の控え状態CSSに混入していた文字列としての \n を正常な改行へ修復。

スマホ操作
- 上部のツールボタンは左右へスワイプして選べます。
- 対戦中のツール列も左右へスワイプできます。
- 図鑑/ダメージ計算/素早さ比較のモーダル本体は従来どおり全画面表示です。

更新方法
GitHub PagesではZIPを解凍し、中身をリポジトリ直下へ上書きアップロードしてください。Pages設定は変更不要です。
PWAで新バージョン通知が出たら「今すぐ更新」を押してください。

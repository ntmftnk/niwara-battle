================================================

1. JavaScript構文
- 変更対象を含むランタイムJS: node --check OK

2. 環境研究 5形式スモーク

- double: 30戦 / 不正なポケモン×技 0 / NaN・Infinity 0

3. 適応性の専用テスト
同じシード・80戦について、外部メタ情報なしと、
「ゴウカイン=高採用だが低勝率 / ウルフレム=高勝率」という
合成済み環境スナップショットを与えた場合を比較。

構築採用回数:
- ゴウカイン: 68 -> 23
- ウルフレム: 44 -> 80
- バブハット: 45 -> 107

これはバランスそのものの評価ではなく、実勝敗を与えると同じ乱数条件でも
次の構築分布が変化することを確認するための機能テストです。

4. 旧研究スナップショット互換
v13.0.1相当で、種族のroster/teamWins/selected/selectedWinsのみを持ち、
新規の moveSetWins / abilityWins / itemWins を持たないメタデータを入力。
5形式各10戦を完走。例外・NaN・Infinityなし。

5. ライブ非シングル わるあがき
実ブラウザで確認。

- 現在ポケモンの全技PP=0、控えにPPあり -> CPUは技を使える控えへ交代
- チーム内の全技PP=0 -> CPUはわるあがきを選択
- ゴーストタイプへダメージが入る
- PPは0のまま
- 使用者に最大HP1/4相当の反動
- 使用者をマジックガードに変更しても反動を受ける
- JavaScript例外 0

6. シングル わるあがき
実ブラウザでタイプ相性/きのみ判定を確認。

- ゴースト相手の相性倍率 = 1
- ノーマル半減きのみはわるあがきに発動しない

7. 補足
研究AIは「機械学習モデル」ではありません。
自己対戦で蓄積した勝敗統計を、ベイズ平滑化と探索項付きの
ヒューリスティックへ逐次フィードバックする適応型研究AIです。
試合数を増やすと結果が蓄積されますが、最終的な環境はポケモン/技データ、
AI評価式、初期条件、シード等にも依存します。

ニワラバトル v13.0.1 修正パッチ
================================

対象: v13.0.0

■ 修正内容

1. 環境研究の「そのポケモンが覚えない技」混入
- 原因: シングル研究で、先にひん死した個体が予約していた行動を、その直後に出た交代先が実行できる経路があった。
- 行動を「選択した個体そのもの」に固定し、ひん死・交代済みなら予約行動を破棄する。
- 技使用統計は「その種の movePool に存在し、かつ実際のセットに入っている技」だけ記録する。
- セット採用統計も種族の習得技で再検証する。
- 旧保存研究に残る不可能なポケモン×技の組み合わせは、表示・CSV・図鑑統計で自動除外する。
  ※旧データの誤記録を正しい使用者へ再配分することはできないため、該当行を除外する方式。

2. はかいこうせん / エレクトロビーム等のデメリットとAI評価
- はかいこうせん系: 命中してダメージを与えた後、次ターンは反動で行動不能。反動ターンにPPは減らない。
- 2ターン技: 1ターン目にPPを1だけ消費して溜め、2ターン目は同じ技を強制。2ターン目を新規の「技使用1回」として二重集計しない。
- エレクトロビーム: 溜め時の特攻上昇は1回だけ。雨 / パワフルハーブでは即時化。
- あばれ技も研究側で継続ターンと終了後こんらんを処理。
- AIは反動ターン・溜めターンを「実効テンポ」として評価へ反映。高威力だけを見て過大評価しない。
- ライブシングル / ライブ非シングル / 環境研究の脅威推定にも同じ考え方を反映。

3. ログ表示順
- 非シングルで、ダメージ → ひんし → 急所/相性 となる場合があった。
- ダメージ → 連続回数 → 急所 → タイプ相性 → ひんし の順に整理。
- 反動ターンは通常技を偽装せず「反動で動けない」という専用行動として処理・表示する。

4. トリプル等で「ひん死した直後の個体が技を使う」対策
- 行動キューに actor（行動を選んだ個体）を固定。
- 解決時に actor がひん死 / fainted / そのトレーナーの現在の場から外れている場合は行動を破棄。
- 研究シングルにも同じ actor 固定を適用し、交代先による予約技の誤実行を防止。

5. 同名ポケモンのログ識別
- 同じ名前のポケモンが複数いる場合だけ、所有者ラベルを自動付与。
- 例: CPU Aのウルフレム / CPU Bのウルフレム
- シングルは プレイヤーA / プレイヤーB（CPU戦ではCPU A / CPU B相当の既存ラベル）を使用。
- ダブル / トリプル / タッグは A1 / B1 等のトレーナーラベルを使用。
- 技、ダメージ、状態、能力変化、残飯などのターン終了処理にも適用。

ニワラバトル v13.0.6 修正パッチ
================================
対象: v13.0.5
アプリバージョン: 13.0.6
Service Worker generation: 22

■ 修正目的
v13.0.5の100,000戦で見られた、推定カウンター評価が実戦の勝敗と乖離し、
数世代周期で上位構築が極端に入れ替わる現象への改善です。

■ 主な変更
1. カウンター候補の実戦実績を学習
  新しい selectedCounterResults は「実際に両軍が選出した種族＋特性の組合せ」と
  「その試合のチーム勝敗」を記録します。これは直接1対1の対面勝敗ではありません。
  実戦サンプルが少ないときは従来の静的相性予測を用いて探索し、
  十分に増えると静的な予測点を弱め、ベイズ平滑化済みの実績点を優先します。
  引き分けは勝ち・負けとは区別します。

2. 直接対面KO実績の評価を修正
  以前は攻撃試行回数に対してKO数を「勝率に近い値」として補正していました。
  KO/被KOの釣り合い、観測数と信頼度を基準にするよう修正しました。
  selectedCounterResults（選出された試合のチーム成績）とは混ぜません。

3. best-responseの過剰反応を緩和
  推定のタイプ無効・特性相性ボーナスの重複した影響を減らし、
  種族探索、特性選択、チーム評価に実戦実績を反映します。
  最初から対策型を排除しないよう、未観測の型は引き続き探索可能です。

4. 代表型の能力配分を改善
  前世代でよく使用されたポケモンの性格・基礎ポイント構成が記録されている場合は、
  実際に使われた構成を代表型に使用します。なければ合法な既定値に戻します。

5. 世代学習・CSV・JSON
  selectedCounterResultsを研究集計、EMA、世代境界、詳細スナップショットに引き継ぎます。
  CSVには以下のsectionを追加します。
   selected_counter_team_outcome
   snapshot_selected_counter_team_outcome
  CSVの既存先頭7列・旧sectionは保持しています。JSONにも同項目が含まれます。
  EMA係数はv13.0.5と同じ0.45です。
  ポケモン別の性格・基礎ポイント・技・特性・持ち物データも継続保存します。

■ 上書きする5ファイル
  app-config.js
  sw.js
  js/app-config.js
  js/research.js
  js/sim-core.js

パッチZIP内のディレクトリ構造を保ち、GitHubリポジトリの同じ場所で上書きしてください。
既存のiconsやindex.html、style.css、その他JSを削除する必要はありません。
GitHub Pagesデプロイ後にPWAで「更新確認」を実行してください。

■ 研究データ互換・注意
- v13.0.5までの研究は引き続き閲覧・保存できます。
- 旧データにない selectedCounterResults は復元できず、更新後の対戦から記録します。
- 比較研究はv13.0.6で新規に開始してください。
- 100,000戦の長期安定性や実環境での周期抑制はまだ実証していません。
- 研究はCPU自己対戦の近似モデルで、人間対戦の使用率ではありません。
- ダメージ/KOの直接対面実績と、選出されたチームの勝敗を混同しないでください。

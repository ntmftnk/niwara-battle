ニワラバトル v13.0.3 研究AI・研究コア修正
========================================

対象
- v13.0.2 からの上書きパッチ
- バージョン: 13.0.3
- Service Worker generation: 19

主な変更

1. 環境研究を世代制へ変更
- 研究を一定試合数ごとの「世代」に分割します。
- 第N世代の結果を固定し、第N+1世代の構築・型選択に利用します。
- 同一世代の途中結果を同じ世代内の後続試合へ混ぜません。
- 複数Worker時も、全Workerが現在世代を完了するまで次世代を開始しない世代バリアを追加しました。
- 目安の世代サイズ:
  * 2,000戦以下: 250戦
  * 10,000戦以下: 500戦
  * 50,000戦以下: 1,000戦
  * それ以上: 5,000戦

2. 「累積勝者強化」から best-response 型へ修正
- 前世代の使用率・勝率だけでなく、上位メタの主要な特性・主要技を組み合わせた代表型を作ります。
- 候補ポケモンについて、代表型からの推定被ダメージ、返しの打点、素早さ、特性による無効化・軽減を評価します。
- 全体勝率が低い種でも、上位メタへ強い特定特性を持つ型は対策候補として探索されます。
- 種族全体の過去勝率による補正を弱め、対策性能の比重を引き上げました。
- 実戦中の「種族+特性」直接対面ダメージ/KO実績も次世代の評価へ使用します。
- 1世代中は前世代メタを固定し、best-response評価をキャッシュして大量試行時の速度低下を抑えます。

3. 環境推移を区間統計へ変更
- 従来の「開始から現在までの累積平均」ではなく、各区間での使用率・勝率を保存します。
- 表示も「1–5,000戦」「5,001–10,000戦」のような区間表示です。
- 「上位3種占有率」は誤解を避け「上位3種 合計採用率」としました。

4. 対策特性を研究戦闘へ反映
研究コアで不足していた特性効果を追加・監査しました。主なもの:
- ぼうおん: 音技無効
- どしょく: じめん技無効 + HP1/4回復
- ひらいしん: でんき技無効 + 特攻上昇（マルチでは引き寄せも反映）
- そうしょく: くさ技無効 + 攻撃上昇
- かんそうはだ: みず技無効 + 回復、炎弱点、天候残効
- ふゆう: じめん技無効（じゅうりょく/うちおとす中を除く）
- かざぐるま: 風技無効 + 素早さ上昇
- ビビットボディ: 優先度技の防御
- しめりけ: 爆発系技の防御
- おうごんのからだ / スイートベール / すいほう: 状態異常防御
- てんねん / いろめがね / ちからずく / フェアリーオーラ等の火力・能力補正
- クリアボディ / しろいけむり / かちき / じきゅうりょく / ぬめぬめ / じしんかじょう
- さいせいりょく / しぜんかいふく / うるおいボディ / ポイズンヒール / かそく
- あめふらし / すなおこし / トリックビルダー / クリーンランド / てんきや

5. 研究技処理の差分修正
- Uターン/ボルトチェンジ系の非シングル研究での交代
- 強制交代技の研究用控え処理
- とどめばり系のKO時能力上昇
- じゅうりょく / うちおとす
- チャージ系のでんき威力上昇
- きあいだめの急所率
- ねをはる
- たくわえる / のみこむ / はきだす
- れんぞくぎり / ころがる
- Beat Up系の近似処理
- 砂嵐ダメージ / グラスフィールド回復 / エレキ・ミストフィールド状態異常防御
- 天候依存回復
- みらいよち系の遅延処理
など、ライブ対戦との差が環境統計を歪める項目を追加・修正しました。

6. 研究データ互換
- 過去の研究結果は引き続き表示可能です。
- v13.0.2以前の途中研究を再開するとv13.0.3の世代制へ移行しますが、過去の累積学習値を世代別に再構成することはできません。
- v13.0.3の効果を比較する場合は、新しい研究を開始することを推奨します。

注意
環境研究は大量試行向けのヘッドレスモデルです。ライブ対戦との主要なデータ・技効果・特性効果を揃えていますが、極端に複雑な専用シーケンスは簡略化される場合があります。研究結果は人間環境の実使用率ではなく、設定したCPU・構築生成・ルールから形成される自己対戦環境です。

ニワラバトル v12.0.0
=====================

v12は「マルチバトル＋環境研究＋図鑑統計」の大型更新です。
既存シングルはv10/v11系の統合ランタイムをそのまま使用し、非シングル形式は新しいフォーマットエンジンで処理します。

■ 追加バトル形式
- シングル：6匹から3匹、場1体（従来形式）
- ダブル：6匹から4匹、場2体
- トリプル：6匹から6匹、場3体
- 6vs6：6匹すべて、場1体
- タッグ：A1+A2 vs B1+B2。各トレーナー6匹から3匹、各トレーナー1体ずつ場へ

ダブル / トリプル / 6vs6 は以下を選べます。
- 対CPU戦
- 2人対戦（同じ端末）
- CPU vs CPU

タッグはA1/A2/B1/B2ごとに、
- プレイヤー / CPU
- 使用パーティー
- CPU強度
を個別指定できます。0～4人の人間参加に対応します。
「対戦モード」はタッグ時には初期配置プリセットとして働き、その後4人を自由に変更できます。

■ マルチバトル
- 複数アクティブ
- 単体対象 / 味方対象 / 相手全体 / 周囲全体 / 味方全体 / 場対象
- 複数対象攻撃の0.75倍補正
- トリプルの位置・隣接判定
- 交代、ひんし交代
- 交代技は技が実際に解決した時点で交代先を選択
- CPUの自動選択 / 自動対戦
- 人間複数時の端末受け渡し入力
- 観戦 / 神視点
- 公開情報に応じた控え表示とログ

公開情報ルール：
- 自分側のHP変動ログ：実数
- 相手側：最大HP比の％
- 観戦：両側％
- 神視点：両側実数
- 相手の未登場控え：???
- CPUは相手の未公開性格・能力P・採用技・持ち物・特性を直接参照しない

■ 環境研究
シングル / ダブル / トリプル / 6vs6 / タッグを別々の環境として研究できます。
Web WorkerによるCPU自己対戦を行い、IndexedDBへ途中保存します。

主な集計：
- 構築採用率
- 選出率
- 先発率
- 選出時勝率
- KO / 被KO
- ポケモンごとの技採用率
- ポケモンごとの技実戦使用回数 / 有効率 / KO
- ポケモンごとの特性採用率
- ポケモンごとの持ち物採用率
- 性格・能力P分布
- 選出対面結果
- 直接攻撃対面 / KO記録

以前の「全体の技・特性・持ち物ランキング」を主表示にせず、ポケモン別統計を中心にしました。

■ 図鑑
図鑑から各形式の最新保存済み環境研究結果を参照できます。
- 使用率 / 選出率 / 先発率 / 勝率
- 技採用率と実戦使用
- 持ち物
- 特性
- 各ポケモンとの選出対面結果
- 直接攻撃対面 / KO

詳細検索：
- キーワード / 図鑑番号
- タイプ1 / タイプ2
- 特性
- 覚える技
- 合計種族値の最小 / 最大
- H/A/B/C/D/Sの最小 / 最大
- 図鑑番号・BST・各種族値で並び替え

■ v11からの更新
GitHub Pagesのリポジトリは全削除不要です。
v12 ZIPを解凍し、中身をリポジトリのルートへ上書きしてください。
新規ファイル：
- format-engine.js
- pokedex-research.js

研究用の以下は引き続き必要です。
- sim-core.js
- sim-worker.js
- sim-manager.js

保存パーティーのlocalStorageキーは維持しています。
環境研究DBも既存の niwaraBattleResearchV11 をDB version 2で継続利用するため、過去研究は可能な限り保持されます。

■ 注意
通常シングルは最も詳細な専用メカニクスを持つ基準エンジンです。
v12の新マルチフォーマットエンジンと高速研究コアは、共通データ・能力値・タイプ相性・主要な場効果・複数対象処理を実装していますが、極端に特殊な専用技・専用特性については今後さらに個別監査する余地があります。
環境研究の数値は「CPU自己対戦環境」の統計であり、人間プレイヤーの実使用率ではありません。

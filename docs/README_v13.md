# ニワラバトル v13.0.0

v13は、v12.0.7までの対戦・AI・環境研究・図鑑機能を維持しながら、今後の拡張で同じ処理を何度も実装しなくて済むように基盤を整理した大型更新です。

## v13の主な更新

### 1. 共通バトルコア基盤
`js/battle-core.js` を追加しました。

共通化した主な要素：
- タイプ相性
- 能力ランク倍率
- 命中期待値
- 連続技期待回数
- AI用の代表威力
- 技の基本的な成立条件
- 相手の公開種族値モデル
- リプレイ記録
- CPU判断記録
- ルールセット保存

シングル、非シングル、環境研究がこれらの共通基礎処理を参照します。

注意：v13.0.0では安全性を優先し、従来シングルと非シングルの全技・全特性の詳細効果処理を一つの巨大な関数へ全面移植してはいません。詳細な効果解決器は既存互換を保ちながら別々に残し、共通化できる基盤から `battle-core.js` へ移しています。今後のv13系で段階的に共通化を進められる構造です。

### 2. バトルリプレイ
ヘッダーの「解析・検証」から、現在または直前の対戦ログをターン単位で確認できます。

- シングル / ダブル / トリプル / 6vs6 / タッグ対応
- 技、交代、状態変化などのログを順番付きで保存
- CPU判断も同じリプレイへ保存
- JSONコピー
- JSON保存
- JSON読み込み

リプレイ形式は `niwara-replay-v13` です。

### 3. CPU判断の可視化
「解析・検証」→「CPU判断」で、CPUが比較した行動候補とスコアを確認できます。

例：
- 技候補の評価値
- 交代候補の評価値
- 推定被ダメージ
- 溜め状態 / あばれ状態による強制行動
- 選択理由

これはデバッグ用の神視点情報です。通常対戦中のCPUが相手の未公開実数値・技・持ち物・特性を読む仕様には変更していません。

### 4. 環境研究2.0
環境研究に推移スナップショットを追加しました。

研究の進行中に一定試合数ごとに、
- ポケモン使用率上位
- 上位3種の占有率
- 使用率推移
を保存します。

v12.0.7で導入した適応型メタフィードバックも維持しています。直近までの研究結果を次の自己対戦構築へ反映するため、一強環境に対して対策側が増える変化を観察できます。

### 5. 共有ルールセット
環境研究で設定できる
- 使用可能ポケモン
- 使用可能技
- 使用可能特性
- 使用可能持ち物
を名前付きルールセットとして保存できます。

同じルールセットを対戦設定でも選択できます。

ルールに違反した保存パーティー / 現在編成では対戦を開始しません。CPUの自動構築も選択中ルールの範囲だけから生成します。

保存キー：
- `niwaraBattleRuleSetsV13`
- `niwaraBattleActiveRuleSetV13`

### 6. 解析・検証モード
「解析・検証」から簡易自己診断を実行できます。

現在確認する項目：
- ポケモン / 技 / 持ち物データ読込
- 技データ必須項目
- 種族→習得技参照の欠損
- 共通AI基礎評価
- 共通コアのバージョン
- 環境研究UIと初期条件

複雑な任意盤面をGUIから完全再現する専用バトルサンドボックスは、共通効果解決器の移行後に拡張できるよう基盤を先に用意しています。

```text

│  ├─ pwa.js             # PWA UI/更新確認
│  ├─ research.js        # 研究UI + 図鑑研究連携（旧2ファイルを統合）

   ├─ README_v13.md
   ├─ MIGRATION_v13.md
   └─ V13_AUDIT.md
```

## 互換性
- 現在編成：`niwaraBattleTeamV5` 維持
- 保存パーティー：`niwaraBattlePartyLibraryV8` 維持
- 研究DB：`niwaraBattleResearchV11` / DB version 2 維持
- v12.0.7までの保存パーティー・研究結果を引き継げます。

`/app-config.js` は重複に見えますが、v12のインストール済みPWAが更新確認時に `./app-config.js` を参照するため、移行互換用として意図的に残しています。v13本体は `/js/app-config.js` を使用します。
